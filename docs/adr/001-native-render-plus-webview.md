# ADR 001 — 렌더링: Direct3D 11 직접 렌더링 + 웹 배경만 WebView2

- 상태: 확정 (2026-11-26, 기획서 7장 투트랙 A)

## 맥락
배경 종류는 셰이더·영상·이미지·웹 네 가지다. 모두 WebView2(브라우저 엔진)로 그릴 수도 있고, 셰이더·영상·이미지는 Direct3D 11로 직접 그리고 웹만 WebView2로 띄울 수도 있다. 이 프로젝트의 목적은 C++ 학습이고, 핵심 특징은 "필요 없을 때 확실히 멈춘다"이다.

## 선택지

| 기준 | 전부 WebView2 | Direct3D 11 + 웹만 WebView2 |
|---|---|---|
| 메모리 | 모니터마다 브라우저 엔진 → 무겁다 | 셰이더·영상은 가볍다 |
| 멈추기 | 페이지 스크립트가 협조해야 한다 | 그리기 루프를 내가 멈추면 끝 |
| C++로 배우는 것 | 창 관리 정도 | Direct3D, Media Foundation, COM까지 |
| 개발 속도 | 빠르다 | 느리다 |

## 결정
직접 렌더링 + 웹만 WebView2. 웹 배경은 웹으로만 할 수 있는 것(웹 비주얼라이저, 시계·날씨 위젯)에만 쓴다.

## 결과와 트레이드오프
- 렌더 스레드·스왑체인·Media Engine을 직접 다뤄야 해서 개발이 느리다. 대신 그게 배우려는 대상이다.
- 멈춤 정책(12장)을 렌더 루프에서 확실하게 지킬 수 있다.
- 웹 배경은 모니터 창 구성이 달라진다(스왑체인 대신 WebView2, Phase 7).

## 다시 검토할 조건
- RAISED 구조에서 Direct3D 스왑체인이 합성되지 않고 DirectComposition으로도 해결되지 않을 때 (Phase 1 스파이크)
- 웹 배경 비중이 셰이더·영상보다 커질 때
