# ADR 002 — 설정 UI: Dear ImGui

- 상태: 확정 (2026-11-26, 기획서 7장 투트랙 B)

## 맥락
설정 창(라이브러리·모니터·멈춤 규칙·오디오·성능·일반)을 무엇으로 그릴지 정해야 한다. 설정 창은 가끔 여는 보통 창이고, 닫으면 렌더링에서 완전히 빠져야 한다.

## 선택지

| 기준 | Dear ImGui | WebView2 웹 UI | WinUI 3 |
|---|---|---|---|
| 언어 | C++ (내가 친다) | HTML·JS(Claude Code) + C++ 메시지 다리 | C++/WinRT + XAML |
| 모양 | 개발 도구 느낌, 꾸밀수록 손이 많이 감 | 자유롭게 예쁘게 | Windows 기본 앱 모양 |
| 난이도 | 낮음 | 중간 | 높음 (설정·빌드가 복잡) |
| 의존성 | 아주 작음 | WebView2 | Windows App SDK |

## 결정
Dear ImGui (Win32 + DX11 백엔드). 같은 Direct3D 장치 위에서 돌고, "매 프레임 UI를 다시 그린다"는 즉시 모드 개념이 단순하다.

## 결과와 트레이드오프
- UI 코드도 C++로 직접 친다 (학습 목적과 맞다).
- 모양은 개발 도구 느낌이고, 꾸미려면 손이 많이 간다.

## 다시 검토할 조건
- 다 만들고 나서 예쁘게 바꾸고 싶어지면 웹 UI로 갈아탄다 (백로그: "웹 UI로 설정 창 다시 만들기").
