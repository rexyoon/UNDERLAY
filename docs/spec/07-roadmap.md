## 16. 로드맵

주 6~8시간, 마감 없는 취미 속도로 18주다. 날짜 대신 주차로 적었다. 순서의 원칙은 하나다. 어느 마일스톤에서 멈춰도 매일 쓸 수 있는 앱이 남는다.

### Phase별 결과와 산출물

| Phase | 주차 | 결과로 보이는 것 | 핵심 산출물 |
|---|---|---|---|
| 0 준비 | W1 | Visual Studio에서 F5로 빈 창이 뜬다 | CMake·vcpkg, 훅, 첫 C++ 창, 첫 테스트, CI |
| 1 바탕화면 | W2–3 | M1 아이콘 뒤에 색이 깔린다 | 구조 감지·붙이기·복구, 트레이, 단일 실행, 탐색기 재시작 대응, Direct3D 합성 검증 |
| 2 Direct3D | W4–5 | 모든 모니터에서 테스트 패턴이 움직인다 | 장치, 모니터별 창·스왑체인, DPI, 렌더 스레드·명령 큐 |
| 3 셰이더 | W6–7 | 셰이더 파일을 저장하면 바탕화면이 바뀐다 | IWallpaper, 셰이더 배경, 핫 리로드, 패키지 읽기 |

| 9 마무리 | W18 | M4 설치 파일로 배포 | 크래시 처리, 장치 손실, 설치 파일, GitHub 릴리스, README |

### C++ 개념 지도 — Phase마다 익히는 것

| Phase | C++ · Windows 개념 | Java·Kotlin과 비교하면 |
|---|---|---|
| 0 | 컴파일·링크, 헤더/소스 분리, `#pragma once`, CMake 타깃 | 패키지·import 대신 include와 링커 |
| 1 | Win32 메시지 루프, HWND, 와이드 문자열(UTF-16), RAII와 소멸자, 람다 → 함수 포인터 | try-with-resources ≈ RAII, 다만 C++은 스코프가 끝나면 무조건 |
| 2 | COM과 `ComPtr` (참조 카운트), HRESULT, 값·참조·포인터, `std::thread`, 뮤텍스·조건 변수 | 모든 객체가 참조인 Java와 달리 C++은 기본이 값 복사 |
| 3 | 순수 가상 함수(인터페이스), `std::unique_ptr`, 파일 입출력, 구조체 메모리 배치 | interface ≈ 순수 가상 함수 클래스 |
| 4 | COM 콜백 객체 구현, 비동기 이벤트 | 리스너 객체를 직접 참조 카운트로 관리 |
| 5 | 열거형 클래스, 순수 함수 설계, 표 기반 테스트 | when ≈ switch, 다만 빠뜨린 경우 경고를 켜 둔다 |
| 6 | `std::atomic`, 메모리 순서, lock-free, `std::span`, `constexpr`, 복소수 | volatile·synchronized와 다른 C++ 메모리 모델 |
| 7 | 비동기 완료 핸들러, JSON 다루기 | CompletableFuture 비슷한 콜백 사슬 |
| 8 | 템플릿 기초, RAII로 외부 C 라이브러리(SQLite) 감싸기, 즉시 모드 UI | 제네릭 ≈ 템플릿, 다만 컴파일 시점에 코드가 생성됨 |
| 9 | 예외 안전성, 크래시 덤프, 릴리스 빌드 최적화 | — |

## 17. 리스크와 백로그

### 리스크

| 리스크 | 가능성 | 영향 | 대응 |
|---|---|---|---|
| Windows 업데이트로 바탕화면 구조가 또 바뀜 | 중간 | 높음 | 구조 감지 + 창 트리 로그, `desktop/`에 격리, 감지 실패 시 안내 후 종료 (바탕화면을 망가뜨리지 않음) |
| RAISED 구조에서 Direct3D·WebView2 합성이 안 됨 | 중간 | 높음 | Phase 1 끝에 먼저 검증. 안 되면 DirectComposition 방식으로 전환 |
| C++ 진입 장벽으로 흥미가 꺾임 | 중간 | 높음 | Phase마다 눈에 보이는 결과, 파일은 작게, "이 파일은 복사로" 예외 허용 |
| 타이핑 양이 많아 지루함 | 높음 | 중간 | Direct3D 초기화처럼 긴 코드는 함수로 쪼개 한 번에 하나씩, 선언을 먼저 치고 Visual Studio의 "정의 만들기"로 틀을 잡은 뒤 내용을 친다 |
| SEASON 등 다른 프로젝트와 겹침 | 높음 | 낮음 | 마감 없는 취미 트랙. Phase가 독립적이라 몇 주 쉬어도 이어 가기 쉽다 |
| 백신 오탐 · SmartScreen 경고 | 중간 | 중간 | 전역 훅 미사용, README에 이유 설명, 서명은 백로그 |
| 샘플 콘텐츠 저작권 | 낮음 | 중간 | 직접 만든 셰이더·영상만 포함 |
